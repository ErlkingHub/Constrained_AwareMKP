## 1. 研究定位

### 1.1 总课题与 MKP 子课题

总课题是**面向组合优化问题的结构感知和策略学习研究**。多维 0-1 背包问题（MKP）是第一个载体：

$$
\max_{x\in\{0,1\}^N}\sum_{i=1}^N p_i x_i\quad\text{s.t.}\quad\sum_{i=1}^N w_{ij}x_i\le C_j,\; j=1,\dots,M,\qquad p_i,w_{ij}\ge 0 .
$$

选择 MKP 作为载体，有四个原因：

- **约束是多维、耦合的。** 同一个物品同时消耗 M 种资源，哪种资源是瓶颈会随构造过程变化。
- **有成熟的运筹结构可以利用。** LP 松弛、对偶价格和代理乘子在 MKP 上是强先验，便于检验“学习能否利用并超越运筹结构”。
- **可行性可以精确判断。** 由于消耗非负，当前不可放入的物品以后也不可能放入，因此可行集合单调收缩，构造过程的 MDP 定义干净。
- **有标准基准。** Chu & Beasley 基准提供 best-known 参考值，可以复核结果。

### 1.2 “结构感知”与“策略学习”在本课题中的含义

| 层面 | 含义 | 对应的贡献线 |
|---|---|---|
| 结构感知 | 表示要能看见问题的约束结构：资源耦合、相对剩余容量的稀缺度、物品之间的互斥与互补、运筹对偶信息 | C2、C3 |
| 策略学习 | 学习“在什么状态下应如何评估资源的价值”，并把这种判断以可审查的方式施加到构造过程中 | C1、C4 |

## 2. 已确定的研究纲领（新项目必须保留）

### 原则 P-1：学习与执行解耦

> **把“资源随状态变化的价值判断”交给学习，把“保证可行的逐步执行”交给固定、透明的规则。**

- **学习层（Controller）**：读取当前残余问题，输出状态级的控制信号，例如各资源的相对价格、不同评分准则的权重。
- **执行层（Executor）**：没有可训练参数，按透明公式把控制信号和固定特征组合成候选物品的评分，只在可行候选中选择，并更新状态。

这样做的研究价值有三点：

1. 可以分别定位“价值判断错了”和“执行规则表达不了”这两类失败。
2. 控制信号有明确语义，可以审查。
3. 可行性由执行层保证，不需要依靠学习。

### 原则 P-2：学习只发生在一个低维、与 N 无关、可解释的接口上

新项目的控制接口（下文仍称 θ，但不限定其具体分量）必须满足以下**接口契约**：

| 编号 | 契约 | 说明与理由 |
|---|---|---|
| I-1 | **维度与物品数 N 无关** | 这是跨规模零样本推理的前提。允许依赖 M，但应注意增长阶数：旧项目的资源对系数为 O(M²)，M=30 时会膨胀（见 L-4）。 |
| I-2 | **不产生逐物品的学习输出** | 物品级评分只能由“θ × 固定、透明的物品特征或基函数”构成。逐物品可学习残差、逐物品 logits 和逐物品 Q 值都会破坏接口（兄弟项目的教训见 L-2）。 |
| I-3 | **每个分量都有可陈述的语义** | 例如“资源 j 的相对价格”“对 LP 约化成本的信任程度”。分量之间应尽量不共线（见 L-4）。 |
| I-4 | **随状态变化** | θ 在每个构造步、或在明确定义的决策点上，根据残余问题重新计算。“动态是否优于静态”本身就是待验证的问题（见 Q-1）。 |
| I-5 | **可行性由执行层负责** | 学习层不承担可行性。是否用掩码或“感知 + 拒绝”是执行层的设计选项，但最终解的可行性由规则保证。 |
| I-6 | **可以训练** | θ 到动作分布的路径要么可微（θ 是确定性中间量，梯度经由诱导的物品分布回传），要么有明确的替代训练方式，不能依靠黑盒超参数搜索。 |

### 原则 P-3：底层“没有参数”不等于底层“弱”，高层贡献必须单独测量

执行层可以携带很强的运筹先验，例如 LP 对偶价格和机会成本。因此每个主张“学习带来收益”的结论，都必须在**同一个执行层、同一推理预算**下，与固定 θ、静态 θ、未训练 θ 做对照（见 L-1、Q-1）。

### 原则 P-4：评估按阶段分开，比较时预算匹配

以下几个阶段必须分开报告，不能混为一个“最终 gap”：

- 单轨迹 greedy；
- 同一策略采样 best-of-K；
- 加入局部搜索或修复后的结果。

不同方法只能在相同阶段、相同预算下比较，并同时报告时间（见 L-3）。

## 3. 核心贡献线：针对 RL 求解 MKP 的痛点

### 3.1 痛点总表

| 编号 | 强化学习求解 MKP 的痛点或局限 | 表现 | 主要对应的贡献线 |
|---|---|---|---|
| PP-1 | **约束只被“屏蔽”，没有被“理解”** | 可行性掩码让输出始终可行，但模型并不知道哪种资源正在变紧、为什么紧。按惩罚处理的方式又会浪费步骤，并引入奖励尺度问题。 | C1、C2 |
| PP-2 | **多资源耦合和机会成本难以表达** | 物品的价值取决于它消耗的是否是瓶颈资源，而瓶颈会随构造过程转移。逐物品 logits 必须把这些因素隐式压进一个标量。 | C1、C2、C3 |
| PP-3 | **规模泛化差** | 输出维度或学到的逐物品分数尺度依赖训练时的 N。在更大 N 上，常见现象是分数分布漂移、性能退化。 | C1、C2 |
| PP-4 | **不可解释、不可审查** | 黑盒逐物品策略出错时，无法回答“错在资源估值，还是错在排序规则”。 | C1 |
| PP-5 | **长期信用分配困难** | 早期选择会阻断后续组合，而终局奖励稀疏，N=500 时一条轨迹有上百步。 | C4、C3 |
| PP-6 | **与运筹结构脱节** | 纯 DRL 方法通常不用 LP 对偶这一 MKP 上最强的先验；经典启发式则只在根节点算一次对偶乘子，之后不再更新。 | C3、C1 |
| PP-7 | **评估口径混乱** | greedy、采样和搜索的结果混合报告，不同参考值（best-known 与 LP 上界）混用，导致“学习的贡献”无法判断。 | 原则 P-3、P-4（方法学） |

### 3.2 贡献线 C1（核心）：在启发式系数空间中行动的分层构造策略

**针对的痛点**：PP-2、PP-3、PP-4、PP-1。

**核心思想**：策略不在物品空间里打分，而在一个**固定启发式评分族的系数空间**里行动。

$$
S_i(s)=\sum_k \theta_k(s)\,\phi_k(i,s),\qquad \theta=g_\psi(s),\qquad
\pi(i\mid s)=\operatorname{softmax}_{i\in\mathcal F(s)}\big(S_i(s)/\tau\big).
$$

其中：

- $\phi_k$ 是固定、透明的物品级基函数；
- $g_\psi$ 是学习得到的状态到系数的映射；
- $\mathcal F(s)$ 是当前可行候选集合。

**推荐的学术叙事：可学习、状态动态的代理乘子。** 经典 MKP 启发式用伪效用 $p_i/\sum_j\omega_j w_{ij}$ 排序，代理乘子 ω 通常取自根节点 LP 对偶，**之后固定不变**。C1 将其推广为：控制器在**每个构造步**根据残余问题重新给资源定价，同时调整多个评分准则的权重。

**与相近范式的区分**（写论文时必须说明）：

| 相近范式 | 区分点 |
|---|---|
| 动态算法配置（DAC） | θ 不是被采样的黑盒超参数动作。它是确定性中间量，梯度经由诱导的物品分布回传，信用分配在物品层面完成。 |
| 神经引导的元启发式（如 DeepACO、NeuroLKH） | 它们学习的是逐边或逐元素的启发式量，规模随实例增长；C1 的接口与 N 无关，并且以资源为索引。 |
| 逐物品的注意力构造策略（如 Kool et al.） | C1 不输出逐物品 logits。 |

**Demo 中的实现形态**（仅作证据，不是模板）：

- **RL_ModelInhance**：θ 从最初的 $M$ 个资源价格加 $\alpha,\beta,\kappa,\tau$ 四个标量，逐步扩展为 v6 的 11 类分量，非重复条目数为 $M+8+M(M+1)/2+K$。执行层 `WeakDecoder` 没有可训练参数（`mkp_Model.py`）。
- **Constrained_AwareMKP**：θ 为价格的对数调整量、四个基元的混合权重和决断性参数，**另外还有逐物品残差 δ**，因此违反了 I-2。

**已有证据**：

- **A**：在 RL_ModelInhance v6 中，180 个 Chu 实例（M=5/10，N=100/250/500）的单轨迹 greedy 平均 best-known gap 为 0.310%，全部解可行且极大。用 N=100 训练的模型在 N=250/500 上零样本运行。
- **A**：在 Constrained_AwareMKP 的同一批实例上，固定静态 LP 价格比的 greedy 为 0.711%，学习后的 greedy 为 0.439%。这个差异混合了逐物品残差 δ 的作用，只是一次运行，不能直接归因于接口。
- **缺口**：v6 已经删除固定 θ 和静态 θ 的评估路径。“动态 θ 带来增量”目前是 **C**。

**新项目需要重新设计的部分**：

- 基函数字典 $\Phi$ 的选择，以及最小充分字典；
- θ 的参数化方式（取值范围、归一化、对资源排列的等变性）；
- 是否需要温度（温度只影响训练采样，不改变 greedy 排序）。

### 3.3 贡献线 C2（核心）：面向残余问题的结构感知状态表示

**针对的痛点**：PP-1、PP-2、PP-3。

**核心思想**：表示的对象是**当前残余问题**，不是原始实例。表示必须让控制器能够读出“资源层面”的判断，因为 θ 是以资源为索引的。

**Demo 中的实现形态**：两个项目都用了物品 token 与资源 token，加上以消耗矩阵为注意力 bias 的双向 cross-attention 和类内 self-attention。RL_ModelInhance 还加入了以下几项：

- 每步对可行集合重新编码；
- 不可行物品退出消息传递；
- 物品–物品关系注意力；
- 选后后果特征；
- 由资源节点读出价格。

**已有证据**：实现为 A；增益为 B，两个项目都没有编码组件的消融。

结构上的经验与“表示需求”详见第 4 节。新项目应从这些需求出发选择结构，而不是从二部图出发。

### 3.4 贡献线 C3：把运筹对偶结构作为学习的锚点

**针对的痛点**：PP-6、PP-2，以及 PP-5 的一部分。

**核心思想**：LP 松弛对偶给出“资源边际价值”的运筹估计。学习的目标不是重新发现它，而是**在它的基础上做状态相关的修正**，并利用 LP 上界提供与尺度无关的归一化。

**Demo 中 LP 的几种用法**：

| 用法 | RL_ModelInhance v6 | Constrained_AwareMKP |
|---|---|---|
| LP 的求解范围 | 每步对残余可行集合求解平滑对偶（`mkp_lp.py`） | 只在根节点静态求解一次 |
| 作为编码输入 | 原始值、约化成本、影子价格、逐边对偶成本分解 $y_jw_{ij}/p_i$、残余上界 | 价格成本、约化成本、价格比排序 |
| 作为执行层的基函数 | $\eta\log(x^{LP}+0.01)+\delta\,r^{LP}$ | 价格比作为基元之一 |
| 作为 θ 的锚点 | 无（π 独立学习，并非对偶变量） | 价格 = 静态对偶 μ × 学习的对数调整 |
| 作为奖励 | 势函数整形 $\Phi(s)=U(s)/\sum p$ | 终局收益除以 LP 上界 |

**已有证据**：三条通路同时开启，没有归因（B）。

**新项目的设计问题**：

- 是否让 θ 直接以对偶价格为基准做乘性修正，从而让“学习 vs 对偶”的对照成为模型本身的消融；
- 每步重算残余 LP 的收益是否值得它的成本（见 L-11）。

### 3.5 贡献线 C4（辅助）：长期信用分配信号

**针对的痛点**：PP-5。

**Demo 中的尝试**：

- **RL_ModelInhance**：
  - PPO + GAE，独立 Critic；
  - 训练期成对续行排序：从同一状态强制选择不同的首个物品，再由更新前冻结的策略完成构造，以终局收益差作为排序监督，并用 KL 约束策略漂移；
  - LP 上界势函数整形。在 γ=1 时，整形只对完整回报做常数平移。
- **Constrained_AwareMKP**：REINFORCE，以同一实例 K 条采样轨迹的平均回报作为基线。

**已有证据**：B 或 D。历史审计显示，排序标签稀疏，冻结续行不是 Q*，短期保留的收益在更长训练中可能回吐。

**定位**：这条线适合作为技术贡献或实验发现，不宜作为主要创新。新项目可以重新选择训练算法，PPO 不是纲领的一部分。

## 4. 结构编码经验（结构无关）

### 4.1 二部图类结构在 Demo 中带来的编码优势

以下优势来自“物品与资源作为两类实体，消耗作为它们之间的关系”这一建模方式，**不依赖**任何特定的图神经网络：

| 编号 | 优势 | 说明 |
|---|---|---|
| E-1 | **对两个维度都有排列不变或等变性** | 物品顺序和资源顺序都不影响结果，不需要位置编码。 |
| E-2 | **N 和 M 都可变** | 同一套参数可以处理不同规模的实例，这是 I-1 的表示侧前提。 |
| E-3 | **资源是一等实体** | 资源有自己的表示，可以直接读出资源级控制量（价格、资源对系数）。这与接口 P-2 天然对齐，而 Gasse 式的变量–约束图是从变量端读出的。 |
| E-4 | **关系上可以携带状态相对的量** | 消耗相对**当前剩余**容量的比例，比原始系数更有信息。MKP 的消耗矩阵几乎是稠密的，稀疏拓扑本身不带信息，信息在关系的数值上。 |
| E-5 | **关系可以分解运筹量** | 把对偶成本按资源拆到每条“物品–资源”关系上，可以告诉控制器“这个物品贵在哪个资源上”。 |
| E-6 | **支持残余问题视角** | 不可行物品可以退出消息传递和池化，表示随可行集合收缩，与执行层的候选集一致。 |

### 4.2 二部图类结构暴露的不足（新结构需要补上）

| 编号 | 不足 | Demo 中的补救 |
|---|---|---|
| G-1 | **物品之间的组合效应只能两跳间接表达**，而构造过程的核心难点恰恰是物品互斥（阻断）和互补 | 加入显式的物品–物品关系（7 维几何关系作为注意力 bias 和 value），代价是 O(N²) |
| G-2 | **均值池化会稀释少数关键候选** | 机会查询注意力、关键差异对比池化 |
| G-3 | **单步状态看不到决策后果** | 选后特征：选择该物品后被阻断的利润质量、资源归因的余量损失 |
| G-4 | **每步全图重编码代价高** | 兄弟项目的做法是静态编码只做一次，每步只注入动态特征 |

### 4.3 新项目编码器应满足的表示需求（与结构无关）

新项目可以选择任意结构，例如集合或超图表示、约束中心的 token 化、矩阵编码、三部图或异构图、静态–动态分离的编码器等，但应逐条说明如何满足以下需求：

| 编号 | 需求 |
|---|---|
| R-1 | 对物品和资源的排列保持不变或等变，支持可变的 N 和 M |
| R-2 | 能产生**资源级**表示，用于读出以资源为索引的 θ |
| R-3 | 输入以当前残余状态为参照（剩余容量、可行集合），而不只是原始实例 |
| R-4 | 能表达物品之间的互斥与互补，且计算量可控（O(N²) 是否可接受需要权衡） |
| R-5 | 关键的少数候选不会在聚合中被稀释 |
| R-6 | 能接收运筹先验（对偶价格、约化成本、上界），并且可以对这类输入做独立消融 |
| R-7 | 每步的计算成本可度量；可行时，将静态部分与动态部分分离 |

### 4.4 不建议直接沿用的 Gasse 式设计

| Gasse 式设计 | 不适合 MKP 的原因 |
|---|---|
| 以稀疏拓扑和 sum 聚合为核心 | MKP 的消耗矩阵是稠密的，稀疏结构不带信息 |
| 通用 MILP 求解器特征 | 不是相对残余状态的量 |
| 从变量端读出逐变量分数 | 违反接口契约 I-2 |
| 只做一轮消息传递 | 难以表达瓶颈竞争 |

Gasse 工作中仍然值得继承的洞察是：**LP 解信息是最有判别力的输入之一，而且图表示可以泛化到更大的实例。**

## 5. 关键洞察与负面经验

| 编号 | 洞察 | 证据 | 对新项目的含义 |
|---|---|---|---|
| L-1 | **执行层“没有参数”，但先验会不断变强。** 从密度公式，到机会项和余量项，到二阶与搭配项，再到 LP 项，执行层的能力持续增强，而高层的增量从未被单独测量 | A（演进记录） | 从项目第一天就保留固定 θ、静态 θ、未训练 θ 三个对照臂 |
| L-2 | **逐物品残差会破坏接口。** 兄弟项目加入 δ_j 后，“纯资源级控制”“可解释性”“N 无关”三项主张同时失效 | A（源码） | 严格遵守 I-2；如需逐物品修正，必须作为单独命名的实验臂 |
| L-3 | **评估预算主导了表面差距。** 兄弟项目的 0.074% 来自 256 次采样加局部搜索；它的单次 greedy 为 0.439%，而 RL_ModelInhance 的单次 greedy 为 0.310%，在 131/180 个实例上更优。另有一次非正式探索：对 RL_ModelInhance 的 greedy 解做局部搜索，下降法得到约 0.261%，ILS 得到约 0.164%（临时脚本，未入库） | A / D | 遵守原则 P-4；搜索只能作为单独命名的阶段 |
| L-4 | **θ 的复杂度膨胀快，且存在可疑冗余。** θ 从 M+4 个分量增长到 M+8+M(M+1)/2+K（M=10 时为 76）。疑似冗余包括：$x^{LP}=\mathrm{sigmoid}(r^{LP}/\upsilon)$，使 η 项与 δ 项单调相关（δ 的学习均值约 0.017 / 0.006，接近 0）；λ 与 ρ 是同一概念的硬版本与软版本；κ 与 β 都在强调稀缺；A 的对角线与 π 重复；温度 τ 不影响 greedy 排序 | A（公式）/ C（冗余判断） | 先用最小字典起步，按组加入并逐组消融；控制资源对项的 O(M²) 增长 |
| L-5 | **一次改多处，就无法归因。** v6 同时引入 LP 输入、LP 评分和 LP 整形，同时删除了固定与静态 baseline | A | 每次只做单因素改动，保留对照臂 |
| L-6 | **难点集中在紧容量和小 N。** 按容量比分层，a=0.25 的平均 gap 为 0.510%（a=0.75 为 0.160%）；M10/N100/a=0.25 达到 1.010%。大 N 的 gap 更小，不代表模型更会规划 | A | 主要指标必须按容量比和 N 分层报告，并单独报告尾部（最差 gap） |
| L-7 | **资源利用率高不等于分配好。** 平均利用率为 99.29%，但 gap 仍然明显 | A | 利用率不能作为约束感知的证据 |
| L-8 | **“能表达”与“能学到”是两回事。** 历史诊断显示，多数错误都存在合法 θ 能纠正的见证，但局部拟合后完整续行仍可能退步 | D | 用诊断区分接口表达受限和学习失败，再决定扩展字典还是改训练信号 |
| L-9 | **更复杂的表示不一定更好。** ResourceRouting 和 readout 改造的历史报告都出现了退化 | D | 表示复杂度的增加需要消融支撑 |
| L-10 | **续行排序标签稀疏，且依赖当前策略。** 冻结旧策略的续行不是 Q*；短期保留的收益可能在后续训练中回吐 | D / B | 信用分配信号需要报告标签接受率、保留率和真实终局收益 |
| L-11 | **每步残余 LP 和 O(N²) 关系的代价不低。** RL_ModelInhance 单实例平均 17.3 秒，N=500 时约 34 秒（含每步 LP） | A | 成本要计入比较；考虑增量 LP、静态–动态分离或只在决策点重算 |
| L-12 | **可行性辅助预测头不提供独立证据**，因为输入中本身就有可行性信息 | A | 约束感知需要用受控干预来定义和检验 |
| L-13 | **复现材料丢失。** 两个项目的被测权重和完整训练配置都没有入库 | A | 从第一天起保存 commit、配置、种子、数据和权重的 SHA，以及逐实例结果 |

## 7. 新项目的开放问题（按优先级）

| 编号 | 问题 | 最低限度的验证方式 |
|---|---|---|
| Q-1（P0） | 在同一执行层下，学习得到的动态 θ 比固定、静态、未训练 θ 好多少？ | 四个实验臂，相同数据、预算和多个训练种子，按实例配对比较 |
| Q-2（P0） | 学习得到的价格是否优于直接使用 LP 对偶价格？ | 对比 π 学习得到与 π := 归一化的对偶 y；也可以以 y 为基准做乘性修正 |
| Q-3（P0） | 失败是因为接口表达受限，还是因为学习失败？ | 合法 θ 见证搜索 + 冻结续行，与控制器的实际输出对照 |
| Q-4（P1） | 最小充分字典是什么？ | 按组消融：一阶资源定价、LP 导出项、组合前瞻项 |
| Q-5（P1） | 哪些表示需求（R-1 至 R-7）真正带来增益？ | 执行层与训练方式不变，只改表示 |
| Q-6（P1） | LP 的输入、评分和奖励三条通路各自的作用？ | 三因素分别开关，并记录成本 |
| Q-7（P2） | 能否跨 N、跨 M、跨数据族泛化？ | 设置独立的最终测试集，并按分层报告尾部 |
| Q-8（展望，C） | 这一接口能否推广到其他“约束定价”类组合优化问题（如覆盖、调度、多背包）？ | 把“资源”泛化为“约束”，执行层泛化为保持可行性的构造器 |

## 8. 实验与证据纪律

1. 每次实验都记录：研究问题、源码 commit、未提交的改动、数据 SHA、训练/验证/评估种子、完整配置、实际优化预算、checkpoint 的 SHA 与选择规则、推理阶段与预算、硬件与计时边界，并保存逐实例结果与解序列。
2. checkpoint 只按合成验证集选择，不按基准测试集的 gap 选择。长期反复查看 Chu 结果属于研究反馈，应设立独立的最终测试集。
3. gap 用带符号的百分数；gap 之间的差值用百分点。best-known 不等于已证明的最优值；best-known gap 与 LP 上界 gap 不能互换。
4. 统计单位是独立实例和独立训练种子；同一实例的多个前缀不算独立样本。
5. 新机制（逐物品修正、搜索、修复、门控干预等）必须作为单独命名的实验臂，不能悄悄并入主方法。
