## 2. 研究边界：对用户三个问题的回答

### 2.1 单轨迹 greedy 对 θ 敏感，需要改动解码器吗？

**不改 argmax 本身，改的是训练信号和测量方式。**

- **敏感的来源：** argmax 作用在接近并列的分数上，因此 θ→解的映射是分片常数，处处有边界（这就是 D1 看到的锯齿形景观）。一旦第一个物品不同，后续状态都会跟着变。但从 §1.2 可以看到，最终解集合只差约 2 个物品。
- **两种常见的“平滑”办法都越界：**
  - 改成采样或 softmax 解码，等于回到多轨迹或随机性；
  - 加入前瞻或修复，等于让解码器承担搜索（B-3）。
- **应该改的地方：**
  1. **训练信号。** v6 学到了动态 θ：它的 θ 是确定性的中间量，训练时梯度经由 softmax(score/τ) 的物品分布回传（PPO+GAE，逐步信用分配），推理时才取 argmax。这条路径对 θ 的梯度是平滑的。我们 T1–T3 的 θ-PG 是“扰动 θ → greedy 回报”，正好直接面对锯齿形景观，所以只能学到常数。这是 T8 要做的单因素对照。
  2. **测量。** 每个决策报告“选择稳定度”：在 θ 的局部扰动下，原选择保持不变的比例。用它来区分“稳健的估值”和“踩在边界上的选择”。

### 2.2 高层学习器能否保证每步给出最优 θ？学 θ 是否等价于直接输出物品？

**不能保证。** 原因有三层：

1. MKP 是 NP 难问题，多项式时间的控制器加 greedy，除非 P=NP，否则无法保证最优。
2. **接口天花板：** 对于给定的状态 s，定义可达选择集

   $$R(s)=\{\arg\max_{i\in F(s)}S_i(s;\theta):\theta\in\Theta\}.$$

   如果最优路径上的物品不在 R(s) 中，那么任何 θ 都选不到它。
3. 学习器优化的是期望终局回报，还有逼近和泛化误差。

**“学最优 θ ≡ 输出最优物品”在什么条件下成立：** 当且仅当 R(s) ≈ F(s)，即 θ 能让任意候选物品胜出。

- 对于线性评分 S_i = θ·φ_i：物品 i 可达，当且仅当 φ_i 是 {φ_j : j∈F(s)} 凸包上的**暴露点**（若 Θ 是一个锥，则只算该方向锥内的那部分）。
- d 固定时，对随机特征，凸包顶点数只按 O(log^{d−1} n) 的速度增长（Rényi–Sulanke；Bentley 等，1978）。因此在构造的**前中期**，|F(s)| 大，ρ(s)=|R(s)|/|F(s)| 很小，θ 只能在少数“极端”候选之间做取舍，这就是**资源估值**；
- 到了**后期**，|F(s)| 只剩几个候选，ρ(s)→1，θ 就退化为**物品指针**。

所以“弱解码器”不是二元性质，而是一个**可以测量的容量**。

**保持边界的可操作定义（新增接口契约 I-7）：**

- **解码器“弱”指三点：** 不做搜索；字典大小 d 固定且与 N 无关；在估值区，ρ(s) 小。它可以携带强的运筹先验（如 LP primal），这正是 C3 的内容，因此“弱”≠“差”。
- **解码器承担了多少精度，有明确的度量：**
  - 未训练默认 θ（D）与全局常数 θ（G）的水平，衡量解码器自身的贡献；
  - G→L 的差，衡量学习的贡献；
  - 学习的贡献再按 ρ(s) 拆成“估值区”与“指针区”两部分。
- **主张只建立在估值区上。** 指针区的增益要单独报告：它在形式上仍满足 I-1 和 I-2，但实质上接近逐物品决策。

### 2.3 最终消融如何证明“是 RL 在承担跨规模、跨分布的约束感知”

**结论必须来自重新训练的对照臂，不能来自对冻结网络的输入干预。** 对冻结网络改输入会产生分布外输入，性能下降可能只是网络对分布外输入失效，并不能证明它依赖这项信息（这也是 T7 不做输入干预的原因）。

最终矩阵（T8 及以后在新项目中执行；固定同一个执行器 E = G-min 字典 + 价格；所有臂都是单轨迹 greedy）：

| 臂 | 构造 | 证明什么 |
|---|---|---|
| D | 未训练的默认 θ | 解码器加人工先验的水平 |
| G / C / S | 全局常数 / 按类别常数 / 开环相位表 | 离线调参和开环动态能做到多少 |
| **L** | RL 闭环控制器 | 主方法 |
| L-res | 控制器**没有物品 token**，只看资源 token 与全局统计（需重新训练） | 若 ≈L：增益来自资源级估值，而不是物品指针 |
| L-blind | 控制器**看不到残余约束**：去掉 slack 和残余 LP 特征，只看根节点信息（需重新训练） | 若退化到 ≈S 或 G：增益来自对残余约束的感知（因果证据） |
| L-cap | 在 ρ(s)>0.5 的步上冻结 θ（沿用上一步的值） | 指针区贡献了多少 |

- **泛化轴：**
  - 训练：合成数据，N∈{50,100,150}，M∈{5,10}，非相关分布；
  - 测试：Chu 上 N∈{100,250,500}（跨规模）、Chu 上 M=30（跨 M）、GK/Weish 等（跨分布，`MKP_dataset/` 中已有）、相关分布的合成数据。
- **论证条件：** 在每个泛化轴上同时满足以下四点，才能写“RL 承担了跨规模、跨分布的约束感知”：
  1. G→L 的增益显著；
  2. L-res ≈ L；
  3. L-blind 显著退化；
  4. 增益主要来自 ρ 小的步。
- 结论应以“学习贡献占比 =(G−L)/(D−L)”的形式陈述，并给出各轴的数值。

## 3. T7：学习价值的位置与接口容量（推理，v6 代码只读，复用 T5/T6 的基础设施）

### 3.1 T7-a：阶段切换（学习价值在哪个阶段）

单轨迹 greedy。按 tau_cap 设定阈值 τ0，在一条轨迹内切换 θ 的来源：

| 臂 | 构造 |
|---|---|
| SL(0.5)、SL(0.8)、SL(0.9) | tau_cap<τ0 时用 S2 调度（均匀价格），之后用 L 的控制器 |
| LS(0.8) | tau_cap<0.8 时用 L，之后用 S2 |

- 每条轨迹记录切换发生的步数、此时的 |F(s)|，以及切换后剩余的步数。
- 结果解读：
  - SL(τ0) 的回收率随 τ0 下降得越慢，说明价值越集中在后期；
  - LS(0.8) 的回收率反映前期闭环的价值。
- 两者可以叠加验证：若价值在不同阶段的贡献近似可加，则 SL(0.8) 与 LS(0.8) 的回收率之和应接近 100%。

### 3.2 T7-b：决策间隔

L 的控制器每 k 步才重新计算一次 θ，中间保持不变，k∈{2, 8}。解码器自身的 LP 和特征仍然每步计算。

- 报告回收率，以及控制器调用次数和耗时。
- 结果解读：k=8 时仍保持 ≥70%，说明闭环信号随状态缓慢变化（是估值）；k=2 时就降到接近 S2，说明它需要精确对准当前这一步的候选集（像指针）。

### 3.3 T7-c：可达选择集、选择稳定度与接口天花板（不做 rollout，只在状态上评估）

- **状态来源：** L 在合成 N100 的 128 例上所走过的全部状态；Chu 上每个 (M, N, 容量比) 类别取前 2 个实例（共 36 例）的全部状态。
- **两个执行器：**
  - E_full：v6 的全部评分项；
  - E_min：只保留 G-min 的 4 项，其余置零，价格均匀。
- 计算方式：每个状态下，与 θ 无关的物品特征（opportunity、reserve、LP primal、companion 基函数等）只算一次；然后对全部 θ 抽样批量计算评分并取 argmax。

**θ 抽样：**
- **全域 R̂_full：** 每个标量在 v6 规定的取值范围内均匀抽样；价格 logits 在 U[−4,4]^M 中抽样；interactions 和 companion 在各自取值范围内均匀抽样。共 2048 个，再加入 L 的 θ 和 S2 的 θ。
- **局部 R̂_loc：** 以 S2 的 θ_c(τ) 为中心，加高斯残差。残差的标准差，按字段取该类别、该进度段内 L 相对 S2 残差的实测标准差（从 T6 的合成迹中估计）。共 512 个。

**对每个状态报告：**
- |F(s)|、|R̂_full|、|R̂_loc|，以及 ρ_full、ρ_loc；
- **选择稳定度：** 局部抽样中，有多少比例与 L 的选择相同；
- 该步 L 与 S2 的选择是否相同。

**汇总方式：**
- 按 tau_cap 的 10 个分位段、按 N、按“L 与 S2 选择不同的步”分别汇总；
- 重点给出 **L 与 S2 选择不同的那些步**上，ρ_loc 和选择稳定度的分布；
- 再把所有步按 ρ_loc<0.2、0.2–0.5、>0.5 分成三个区，分别给出各区内 L 与 S2 选择不同的步数占比。

**接口天花板（只在合成 N100 上做，MILP 最优解在 `cache/milp_*.npz` 的 `solution` 字段里）：**
- 沿 L 的轨迹，逐步报告两件事：L 的选择是否属于 x\*；R̂_full(s) ∩ x\* ∩ F(s) 是否为空。
- **接口内的预言机 rollout：** 每一步，在 R̂_full(s) ∩ (x\* 中尚未选的物品) 里，选 S2 评分最高的那个；如果这个交集为空，就退回 S2 的 greedy 选择，然后继续。
  - 对 E_full 和 E_min 各跑一次，报告最终 gap，以及第一次出现空交集的位置。
  - 这个结果是“接口在知道 x\* 的情况下最多能做到多少”，作为 Q-3（表达受限还是学习失败）的直接量化。
  - 注意：x\* 可能不唯一，所以这个天花板是一个下界。

### 3.4 必要测试（只加 2 项）

1. 当 θ 抽样只包含 L 的 θ 时，R̂ 恰好等于 {L 的选择}。阶段切换臂在 τ0=0 时与 L 逐位一致，在 τ0=1 时与 S2 逐位一致。
2. 接口内预言机 rollout 的每一步都满足可行性；最终解可行且极大；若全程交集非空，最终解应满足 ⊆ x\*，再由 greedy 补齐到极大。

1. T7-a 和 T7-b：各臂在 Chu 和合成集上的 gap、相对 L 和相对 G 的配对差与 p、回收率、切换统计、耗时。
2. T7-c：上面列出的各项分布表。
