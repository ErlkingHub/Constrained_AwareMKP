### 1.2 结论

**T0-1：δ_j 对单轨迹 greedy 没有实质贡献。**
- a − b = −0.013 pp，不显著；在 sample256 下 δ 反而显著有害。
- 历史上 |δ| 均值约 2.02 只说明 δ 的幅度大，并不说明它改变了 greedy 排序。
- **勘误：** 迁移指导 §0 第 2 条“去掉 δ 后 greedy 明显退化”不成立。main_v1 去掉 δ 后约 0.60% 的结果，来自执行器形式和训练方式，而不是 δ 的缺失。

**T0-2：低维、无逐物品输出的动态 θ 可以学到真实的 greedy 增益。**
- b − c = −0.133 pp（p≈1e-8），增益集中在紧容量（α=0.25）和中小规模的实例上。
- 这是 Q-1 方向上的**存在性证据**（单个 checkpoint，不是多种子结论）。
- 它也给出了 T1 的现实目标：新执行器上的 learned greedy 做到约 0.45–0.48%，即相对新 fixed（0.611%）改善约 0.13–0.16 pp。

**T0-3：0.074% 来自多采样和搜索，与 θ 无关。**
- 加入 ILS 后，a、b、c 之间没有差别：greedy+ILS 为 0.164–0.166，sample256+ILS 为 0.064–0.065。
- c 与 c_fullfixed 在 sample256+ILS 上相差 0.052 pp。这只来自采样温度 κ 的校准，与 θ 的排序无关。
- 按迁移指导 T0 的决策规则：**主线只看 greedy，搜索阶段降为附录。** 在 θ 臂之间，ILS 没有区分力，后续迭代可以不再每轮都跑。

**T0-4：新旧固定执行器可以比较。**
- 新 fixed 为 0.611%，旧固定 c 为 0.583%，配对差 +0.028 pp；在 M=10、α=0.25 上新执行器略差。
- 新 fixed 与 main_v0 去掉 δ 后的学习策略（b）相差 0.161 pp，这就是 T1 需要靠学习补上的距离。

**T0-5：迁移指导中 T2 的立论需要改写。**
- “用阻断基函数 G2 替代 δ 的作用”已经没有依据，因为 δ 本身就不起作用。
- G2 今后只能以“扩展 θ 的表达能力”立论，并且要先拿到 §3 中 B2 的余量诊断证据。

### 2.2 训练过程中的现象

| 现象 | dynamic | static |
|---|---|---|
| α 顶到上界 2.5 | epoch 1 起，均值 2.45–2.50 | epoch 1–16 一直在 2.50，之后约 2.2 |
| \|u\| 均值 | 0.13 → 1.6 | 约 0.3–0.44 |
| 全局 T | 0.333 → 0.270（10 个 epoch） | 0.333 → 0.201（40 个 epoch） |
| 合成验证 gap（MILP 参考） | ep0 为 2.76，最好 2.45（ep9） | ep0 为 3.68，最好 2.59 |
| 初始化时的验证 gap | **没有测量**（没有 epoch −1 验证） | 同左 |

- 作为参照，旧 dual-ratio greedy 在同一验证集上为 N100_M5 1.02%、N100_M10 1.43%（log.txt 开头）。
- 新 fixed 在初始化时的验证 gap 应该与此接近。因此训练从第一个 epoch 起就比初始化差了 1.5–2.5 pp，并且之后一直没有回到初始化水平。
- 由于缺少训练前的验证，checkpoint 选择规则无法暴露这一点。

### 2.3 机制判断：锐度和 θ 混在了一起（C 级假设，证据强，需由 T1-R 验证）

1. 执行器分数 `s = α·log p̃ − log Σ λ r/(c_rem+1)` 没有做归一化，softmax 有多尖锐完全取决于 α 和 \|u\| 的绝对尺度。
2. 初始策略在 T=1/3 下几乎是均匀分布：fixed 臂的 sample64 gap 高达 6.7%，而 main_v0 需要 κ≈86 才够尖锐。REINFORCE 最先、也最强的信号就是“变尖锐”。
3. 唯一专职负责锐度的参数是全局 log T。它只受 lr=1e-4 的 Adam 步长驱动：dynamic 10 个 epoch 只降了 0.06，static 40 个 epoch 最终约 0.20。下降速度接近 Adam 的最大步长，说明锐度需求远远没有得到满足。
4. 于是梯度借道 θ：α 在 1–2 个 epoch 内顶到上界，\|u\| 被放大。增大 α 相当于同时调高锐度和加重收益，它扭曲了 greedy 排序（过度偏重高收益物品），而这在紧容量下伤害最大，与分层结果一致。
5. main_v0 没有这个问题，因为它对各基元做 z-score，还有一个独立、没有上界的 κ 头专门吸收锐度。迁移指导 §3 删掉了 z-score 和 κ，只留下一个学习率受限的全局 T 来接替，这是**指导方的设计疏漏**，不是 Codex 的执行错误。

**结论边界：**
- 这次是**训练信号和参数化导致的学习失败**，不能据此判断 (u, α) 接口的表达能力，Q-3 仍然没有答案。
- 不能据此判断“动态是否优于静态”，Q-1 也仍然没有答案。

### 2.4 为什么不做 T1 三种子正式实验，也不进入 T2

1. 用三个种子复制一个已知有缺陷的训练，没有信息量。
2. T2 的 γ·blocked 项同样不受尺度约束，会继续被当成锐度通道，问题不会消失。
3. T2 的原立论已被 T0-1 否定（见 T0-5）。
4. 迁移指导 §6 的停止条件已经触发：learned_dynamic 相对 fixed 的增量显著为负。

### 3.1 A：把锐度和 θ 解耦（单因素改动）

**A1 执行器做逐步标准化。** 在 `WeakDecoder.__call__` 中，先按现有公式算出原始分数 s，再只在当前可行集 F(s) 上做标准化：

```
z_i = (s_i − mean_{F} s) / (std_{F} s + 1e-6)      # float32；不截断；总体标准差
|F| = 1 时 z_i = 0；不可行物品仍为 NEG；已完成的行保持现有的 no-op 处理
π(i|s) = softmax_{i∈F}(β · z_i)
```

- 标准化没有可训练参数，仍是透明的执行器。它是 main_v0 对基元做 z-score 在新公式上的对应物。
- greedy 的 argmax 不受正仿射变换影响，所以理论上 greedy 结果不变。
- **验收：** fixed 臂在 Chu 180 上的 greedy 必须逐实例复现 `results/t1_fixed180/.../per_instance.csv` 中的目标值（均值 0.61070129%）。若因浮点并列出现差异，报告受影响的实例数和原因；差异超过 2 个实例时停下回报，不要继续。
- 同样，learned_static 和 learned_dynamic 现有 checkpoint 的 greedy 结果也应保持不变。用它们做一次回归检查。
- 训练时 std 的梯度路径保留，不 detach。

**A2 改用共享的固定逆温度。**
- 主实验设置 `temperature_mode=fixed`，`temperature_init=1/β0`（复用现有的 `global_T`，不新增 θ 分量）。
- 所有臂（包括 fixed 和 untrained 的采样阶段）使用同一个 β0，以消除 T1 评测中采样阶段的温度混淆。
- `temperature_mode=learned` 保留为具名选项，T1-R 不使用。
- 评测时的 `sample_temperature` 保持 1.0。

**A3 校准 β0（只用合成验证集，不碰 Chu）。**
- 设置：fixed θ；β∈{1, 2, 4, 8, 16, 32, 64}；合成验证集为现有的 N=100、M=5/10，每组 64 个实例，共 128 个，以 MILP 为参考。
- 报告：greedy gap（应与 β 无关，作为自检）、sample16 的均值 gap、best-of-16 gap、平均每步熵。
- 选择：取 best-of-16 最好的 β 作为 β0；若并列，取较大的 β。
- 产物：`results/t1r_beta_calib/` 下的 CSV 和 meta。

**A4 训练器补充。**
- 训练开始前做一次 epoch −1 验证，结果写入 val_log 并参与 best 的选择。这样“训练不如初始化”时，最终会选中初始化的 checkpoint，并且能在日志中看出来。
- 每 log_every 步追加三项：
  - α 距边界小于 0.02 的比例（分上界和下界）；
  - \|u\| > 0.95·u_max 的比例；
  - 标准化前原始分数在 F 上的标准差均值，用来观察 θ 是否仍在被当作锐度使用。

**A5 单元测试。**
- 标准化后，fixed 臂的 greedy 与标准化前逐实例一致（小实例）。
- \|F\|=1 和已完成行不产生 NaN。
- 物品和资源排列后，greedy 选出的集合不变。
- 梯度有限。
- 现有 31 项测试全部通过。

### 3.2 B：静态 θ 余量诊断（不训练，可与 A 并行）

**命名为诊断，不进入方法成绩。** 目的是回答 Q-3 的一部分：在 (u, α) 接口内，greedy 还有多少可达的空间。

- **数据：** 同 A3 的 128 个合成验证实例（主）；Chu 中 N=100 的 60 个实例为次要，结果单独标注为“基准诊断”，不能参与任何选择。
- **B1 常数 α 扫描：** u=0，α∈{0.5, 0.75, 1, 1.25, 1.5, 2, 2.5}；报告 greedy gap 及其相对 α=1 的配对差，按 M 和容量比分层。用来检验“α=2.5 有害”这一机制推断。
- **B2 逐实例静态 θ 搜索：**
  - 搜索空间：去均值后的 u∈[−3, 3]^M，α∈[0.5, 2.5]；目标是 greedy 目标值（最大化）。
  - 预算：每个实例先随机采样 256 个 θ（包含 fixed θ 本身），再用 CMA-ES 或坐标局部搜索追加 256 次 greedy 评估，共 512 次。
  - 报告：可达 greedy gap、相对 fixed 的配对差（均值、中位数、p90），以及“改善 >0.1 pp 的实例比例”。
  - 另外报告找到的最佳 θ 的 α 和 \|u\| 分布，回答它们是否落在边界上。
- **解释纪律：**
  - 搜索到的结果是**静态 θ 可达余量的下界**；动态 θ 的可达余量不低于静态。
  - 某个实例找不到改进，不证明不可能改进。
  - 这只是诊断，不能当作方法的推理成绩。
- **产物：** `results/t1r_headroom/`，含逐实例 CSV、最佳 θ、预算和用时。

| 介于两者之间（余量为 0.05–0.13 pp） | 不确定 | 由 Claude 结合分层结果和最佳 θ 分布另行裁定 |
| learned_static 显著优于 learned_dynamic | 动态更新可能有害或难以训练 | 记录下来，在 T1 正式实验中重点检验，不立即改变方向 |
