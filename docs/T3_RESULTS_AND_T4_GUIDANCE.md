## 3. 结论

- **T3-1（执行器，Q-6/Q-4）：** 在 G0+G1 之上，残余 LP 锚点、root/residual x^LP 评分和阻塞基都没有带来 ≥0.1 pp 的改进；root x^LP 有害。**最小充分字典仍是 G0+G1**（价格 + α）。T3 的代码保留，默认关闭。
- **T3-2（学习）：** 这是第三种字典（G0+G1、加 G2、加 G3）上出现的“学习 → 全局常数”。按可观测类别条件化的余量 <0.04 pp。旧项目 v6 中“η 按 M 学到 0.75 / 1.42”的结论在本框架下**没有复现**。
- **T3-3（机制）：** E[R(θ)] 在锯齿景观上的最优点是一个常数，因此**任何输出单个 θ 的策略**都只能学到常数。单轨迹余量来自搜索；这是结构性结论，与具体字典无关。

## 4. 方向决策：选方向 2（SMS），否定方向 1

- **否定方向 1**（学习少数随类别变化的系数，如 η）：交叉拟合显示 η 的分层余量为 0，T3-b 中 η 和 γ 坍缩为常数，三种字典的结论一致。继续在这个方向上投入，只能得到“学习等于调参”。
- **选择方向 2：**
  - D1 中，在 fixed 附近按 1σ 扰动取 best-of-32 得到 **0.321**，优于每实例搜索得到的 θ\*（0.450），也优于逐物品采样 β0=8 的 best-of-16（**0.380**，A3）；
  - T3-a 的 50/20/50 现象再次表明，θ（执行器）扰动是一种很强的多样性发生器。
- **学习如何回到故事里（C1 改写为可检验的新假设）：** T1 失败是因为 E[R] 目标会把锯齿景观平滑掉。改成 **max@K 目标**（K 个 θ 抽样中最好的那个的期望）后，最优的提议分布 q(θ|x) 就不再是一个点，而是有宽度、有方向的分布，例如“在哪些资源价格方向上应该扩散得更开”。这是 T4-b 要检验的问题。
  - 如果 T4-b 成功，叙事为“学习 SMS 的提议分布”；
  - 如果失败，叙事为“SMS 作为启发式阶段 + 学习负结果及其机制”，依然诚实而完整。

## 5. T4-a：SMS 测量（本轮核心，固定臂，不训练）

### 5.1 定义

- **执行器：** F0，即 `runs/t1p_static_s1234/config.json` 的模型配置（root 锚点，theta_groups=`["price","alpha"]`，α_init=1，不使用 lp/block），以 `theta_override` 的方式运行。**不使用 residual LP**（它的成本会乘到每条轨迹上），也不使用 γ。
- **θ 抽样：** 在激活前空间中，以 F0 为中心抽样：
  - `v = 0 + s·0.05·ε_u`，ε_u∈R^M；
  - `z = logit(0.25) + s·0.3·ε_α`；
  - 经 `theta_from_pre(v, z, u_max)` 激活。这与 D1（`scripts/t1p_lottery_check.py` 中的 `perturbed`）及 θ-PG 的 σ 定义一致。
  - `dims` 控制只扰动 u、只扰动 α，或两者都扰动（`uα`）。
  - **第 0 条轨迹固定为中心点 θ**（即 F0 greedy），保证 best-of-K ≥ F0。
  - 不使用 antithetic。ε 由 `torch.Generator(seed=paired_seed(seed, instance_id, "sms", tag))` 按固定顺序生成。
- **物品采样基线** `sample(T_eff)`：fixed 臂，decode=sample，有效温度 T_eff = `temperature_init × sample_temperature` ∈ {0.125, 0.333}，其中 0.125 即 β0=8。**第 0 条同样固定为 F0 greedy**，保证两族的比较对称。
- **混合方案** `hyb(Kθ×Ks)`：Kθ 个 θ（第 0 个为中心点），每个 θ 下做 Ks 次物品采样（取 T_eff\*）。总轨迹数 = Kθ·Ks。

### 5.2 代码（新增为主，不改模型）

- **`mkp_evaluation.parse_stages`：** 新增 `theta{K}`（物品层面 greedy）和 `hyb{Kθ}x{Ks}`，两者都可以加 `+ILS`。spec 增加 `theta_k`、`item_k` 字段；旧 stage 的解析结果逐字段不变。
- **`mkp_config.EvalConfig`：** 新增 `sms_dims: str="ua"`（取值 u/a/ua）、`sms_scale: float=1.0`、`sms_include_center: bool=True`，并写入评测协议 SHA。
- **`Benchmark_zeroShot.evaluate_stage`：**
  - 对 theta 和 hyb 两类 stage，构造形状为 (K, M) 和 (K,) 的 `theta_override` 字典，传给 `model(..., num_samples=K, decode=greedy|sample)`。B=1 时这条逐轨迹 override 的通路已经可用（D1 用过）。
  - 只允许 `fixed` 臂；learned 臂遇到 theta 或 hyb stage 时报错，直到 T4-b 接入为止。
  - 分块（`max_rollouts_per_chunk`）时，θ 抽样要先一次性生成，再切片，以保证分块不改变抽样结果。
  - `+ILS` 沿用现有的池化逻辑（`ls_pool=16`），不做改动。

## 6. T4-b：用 max@K 目标学习 θ 提议分布（本轮只写代码，不训练）

### 6.1 模型

- 只用 static 控制器（t=0 决策一次）。新增配置 `ModelConfig.theta_sigma_head: bool=False`，默认关闭时行为逐位不变。
- 开启后，`StrategyController` 增加 σ 输出：
  - 每个资源一个 `s_u`（与 `price_head` 并列的单输出小头），再加一个标量 `s_α`（`scalar_head` 多一个通道）；
  - σ_u = σ_u0·exp(1.5·tanh(s_u))，σ_α = σ_α0·exp(1.5·tanh(s_α))；
  - 头的权重和偏置都初始化为 0，即 σ=σ0。σ0 = Θ\* 的 s × (0.05, 0.3)；不扰动的维度把 σ 固定为 0，不参与抽样，也不产生 logp。
- 均值头沿用现有初始化（u=0，α=alpha_init）。因此**未训练时 = 各向同性的 Θ\***，与 T4-a 选出的固定臂一致。
- `sample_theta_pre` 和 `theta_pre_log_prob` 要支持**张量 σ**；当 σ 依赖于参数时，logp 中必须包含 **−log σ** 项。
- `theta_override="fixed"` 的行为不变。评测时增加 `sigma_override=σ0`，用于“只学 μ”的归因臂。

### 6.2 训练信号 `signal="theta_maxk"`

- 每个实例抽 K 个 θ，物品层面 greedy，得到 R_k。
- 优势：**A_k = max_j R_j − max_{j≠k} R_j**，即留一法 max 基线。这样只有 argmax 样本非零，取值为最优与次优之差；出现并列时全部为零。这个基线不依赖 θ_k，所以估计是无偏的。
- **必须关闭 antithetic**（`theta_pg_antithetic=True` 时报错），否则留一法基线会通过 −ε 与 θ_k 相关。
- 损失：`−mean(A.detach() · logq)`，可以保留 `adv_normalize`（只缩放幅度）。
- 训练日志：`R_maxK`（K 个中的最好值）、`R_center`（均值 θ 下的 greedy 结果）、`frac_adv_nonzero`、σ_u 和 σ_α 的均值和极值、u 均值头的 |u|。
- 验证集的 gap 用 **best-of-K（K=16）** 计算，与训练目标一致；best.pt 按这个指标挑选。

### 6.3 配置与运行

- **`scripts/run_t4b.py`：**
  - 从 `runs/t1p_static_s1234/config.json` 继承，设置 `theta_update=static`、`signal=theta_maxk`、K=16、B=64、10×250、seed 1234、`theta_pg_antithetic=False`、`theta_sigma_head=True`；
  - σ0 和 dims 读取自 `results/t4a_sms/selection.json`；
  - 缺少选择文件，或选择文件只是 smoke 产物时，拒绝运行；
  - 默认只生成 `results/t4b_configs/t4b_static_maxk16_s1234.json`，加 `--train` 才启动训练。
- **评测命令**（训练后由用户运行）：
  - Chu 上跑 `theta16,theta64,theta64+ILS` 三个 stage；
  - 臂为 `fixed`（Θ\*）、`learned_static`（q_φ）、`learned_mu_only`（σ 覆盖为 σ0）；
  - learned 臂按自己的 μ 和 σ 抽样，第 0 条固定为均值 θ 的 greedy 结果。

## 7. 必要测试（只加这 3 项）

1. `theta1` 与 fixed greedy 逐位一致。同一个 seed 下：`theta256` 的前 16 条与 `theta16` 逐位一致；改变 `max_rollouts_per_chunk` 不改变结果。旧 stage 的解析结果不变。
2. `theta_maxk` 的优势函数：用构造好的 R 检查——只有 argmax 样本非零且等于最优与次优之差；并列时全部为零；antithetic=True 时报错。
3. σ 可学习时，`theta_pre_log_prob` 与 `torch.distributions.Normal(μ, σ).log_prob` 求和的结果一致（包括 log σ 项和常数约定；常数可以统一省略，但要与 Normal 只差一个常数）。`theta_sigma_head=False` 时，T1-P 的 checkpoint 加载和 greedy 结果都逐位不变。
