# main_g1 实现与实验说明

## 1. 实现范围与文件职责

本分支从当前初始化提交重新实现，不继承旧 Demo 的逐物品残差、搜索和历史性能结论。
本说明描述源码已经实现的机制；其性能增益均待匹配训练与评估验证。

| 文件 | 职责 |
|---|---|
| `mkp_config.py` | 模型、数据、训练、评估的默认配置与验证；JSON 部分覆盖 |
| `mkp_data.py` | 四个合成数据族、原始数据校验、Chu 适配、根 LP |
| `mkp_env.py` | float64 原始量记账、严格可行状态转移、残余势函数、固定成对特征 |
| `mkp_Model.py` | 残余集合编码器、资源级 Controller、独立 Critic、无参数 Executor |
| `mkp_Trainer.py` | 完整轨迹 PPO、GAE、合成验证、日志、模型选择及续训 |
| `train_ConstrainedMKP.py` | 简洁训练入口 |
| `Benchmark_zeroShot.py` | 五臂、分阶段 zero-shot 评估及 CSV/JSONL 产物 |
| `mkp_utils.py` | 路径、随机数、设备、源码快照、Git/硬件记录和 checkpoint |

默认训练只用 `N=100, M∈{5,10}` 的弱相关合成实例。验证集独立种子且固定，使用相同训练分布，
按 N/M/数据族/容量比的笛卡尔积轮转生成；若 `validation_instances` 少于格数，并不保证每格覆盖。
Chu 270 个实例涵盖 N=100/250/500、M=5/10/30、容量比约 .25/.5/.75。
合成“弱相关”定义不等于声称与 Chu 原始生成分布完全一致。

## 2. 状态、表示与接口

原始数据形状为 `p[N]、w[N,M]、C[M]`。每步状态包含剩余容量、已选物品、累计收益和可行集 F。
只有满足 `used + w_i <= C` 的未选物品可以执行；非负消耗保证可行集单调缩小。
终止于没有可行物品，得到可行且极大的解；**极大不等于最优**。

编码器只接收可行物品，固定输入形状为 `item[F,8]、resource[M,12]、ratio[F,M]、global[8]`。
物品特征包含归一化利润、相对剩余容量消耗的均值/最大值/标准差、阻断利润比例、
最佳兼容伙伴利润，以及 LP 约化利润/成本。资源特征包含剩余比例、可行比例、
消耗统计、利润加权消耗、阻断/兼容归因及独立可关闭的 LP 信息。
共享 MLP 生成内部物品表示，通过消耗加权池化和最大池化传到资源 token，
资源间交换均值/最大值，再池化出状态表示。

| 交接要求 | 当前实现及限制 |
|---|---|
| R-1 可变 N/M、排列性质 | 共享映射、无位置编码；资源价格等变，状态权重不变。分数完全并列时 greedy 用原始索引破平局，不能主张解序列严格排列不变 |
| R-2 资源级表示 | 每个资源 token 经共享标量头读出价格修正 |
| R-3 残余状态 | `w/remaining`、剩余容量、可行候选每步刷新；不可行物品退出编码池化 |
| R-4 互斥与互补 | 精确计算两物品是否可共同放入、阻断利润比例、最佳兼容伙伴；这是局部结构特征，不是多步最优值或测试期搜索 |
| R-5 少数关键候选 | 最大池化和利润/资源加权统计补充均值；有效性待消融 |
| R-6 LP 信息及消融 | `lp_input`、`lp_anchor`、`lp_score`、`shaping_coef` 分别控制输入、价格锚点、评分和奖励通路 |
| R-7 计算成本 | 根 LP 每实例一次；原始张量共享、固定特征按状态缓存；成对特征 O(F²M)，分块峰值 O(chunk·F·M)，仍需测量大规模成本 |

成对输入开关 `pair_features` 与评分开关 `pair_score` 分离：做表示消融时只关闭前者，保持执行器相同。
默认同时启用；关闭两者可测量较小字典和计算成本。没有实现增量神经编码，神经编码每步重算。

## 3. θ 与固定评分

Controller 唯一输出为 `Theta(prices[M], weights[4])`，总维度 M+4，与 N 无关。
资源价格与权重分别归一化；没有逐物品可学习输出、残差、Q 值或可学习解码器。

设根 LP 非负对偶价格为 y。容量缩放锚点 `a_j ∝ y_j C_j`，全部为零时退回均匀价格。
学习器默认再混入 `lp_anchor_mix=0.05` 的均匀质量，避免根状态零对偶资源以后始终不可定价：

`a'_j = (1-mix)*a_j + mix/M`

`δ_j = price_log_bound * tanh(head(resource_j))`

`prices = softmax(log(a') + δ)`

关闭 `lp_anchor` 时 a 为均匀价格。`lp_dual` 基线使用原始 a，不使用学习器的混合或修正。
`weights=softmax(head(global))`，禁用的基函数在 softmax 之前屏蔽。

固定字典为：

1. 资源价格密度：`log(p_i/p_max + eps) - log(Σ_j prices_j*w_ij/C_j + eps)`；
2. 直接利润：`p_i/p_max`；
3. LP 约化利润：`(p_i - Σ_j y_j*w_ij)/p_max`；
4. 负的阻断利润比例：选择 i 后无法再选择的其他可行物品利润 / 当前可行利润总和。

每列在当前可行集中心化并除以标准差（带 eps）；默认不裁剪，`basis_clip` 可显式配置。
`S_i=Σ_k weights_k*φ_ik`，`π(i|s)=softmax_F(S_i/temperature)`。
可行性掩码由环境给出；训练从 π 采样物品，greedy 取最大分数。固定温度不改变 greedy 排序。
原始单位中的容量与利润记账使用 float64，网络输入和网络参数使用 float32。

固定/LP 基线权重均为 `(1,0,0,0)`；静态学习臂固定整个根 θ，但可行集与固定残余基函数仍随状态变化。
所有臂使用同一个执行器与轨迹预算，记录各自耗时；这不意味着各臂计算时间相同。

## 4. 长程信用分配

每轮采样多个独立合成实例，每个实例完整构造到终局，再进行 PPO 更新。
决策动作是物品索引，θ 是确定性中间量；梯度从诱导动作分布经固定评分函数传到控制器。
独立 Critic 拥有自己的编码器和参数，不输出逐物品值。

默认 `reward_mode=terminal, gamma=1, gae_lambda=1`：只有最后一步得到 `objective/U_root`，
其中 U_root 为根 LP 对偶上界。完整轨迹终止 bootstrap 为零：

`δ_t = r_t + γV(s_{t+1}) - V(s_t)`

`A_t = δ_t + γλ A_{t+1}`

`target_t = A_t + V_old(s_t)`

当 γ=λ=1，终局收益能进入所有早期动作的优势，Critic 目标是该轨迹的最终总收益/上界。
这避免人为截断回报，但不能保证低方差、因果归因正确或成功学到长程规划。
`reward_mode=incremental` 改成每步新增利润/上界，完整回报不变，Critic 目标改为剩余收益。
`gae_lambda<1` 改变优势估计中的偏差/方差；γ 固定为 1，保持原始总利润目标。

势函数使用固定根对偶在残余状态上构造上界，无须每步重新求 LP：

`U_res(s)=min(Σ_F p_i, y·remaining + Σ_F max(0,p_i-w_i·y))`

`Φ(s)=U_res(s)/U_root`，终止 Φ=0；整形奖励 `r'_t=r_t+η(Φ(s_{t+1})-Φ(s_t))`。
γ=1 时完整回报只平移 `-ηΦ(s_0)`。这是有效残余上界，不是精确残余 LP 最优值。
默认 η=0；它与 LP 输入、评分、锚点可独立开关。

PPO 保存更新前 log-prob 和 value；同一批完整轨迹经过多 epoch、小批次更新，
优势在整批决策上统一标准化。策略使用 clipping、熵正则和 KL 提前停止；
Critic 拟合冻结的回报目标。日志记录真实优化步数、决策数、早/中/晚期优势幅度、
回报标准差、策略/价值损失、KL、梯度范数和耗时。
同实例的步骤不作为独立统计样本。

## 5. 实验纪律与建议顺序

| 研究问题 | 可执行的单因素设置 | 必须保持或报告 |
|---|---|---|
| 动态资源估值是否增益 | 默认五臂：dynamic/static/fixed/untrained/lp_dual | 同数据 SHA、单轨迹或相同 K；实例配对、多训练种子 |
| 长程信用分配 | terminal λ=1；incremental λ=1；terminal λ=.95；独立整形 η>0 | 每次只改一个参数；同实例/更新预算及真实优化步数；最终收益 |
| LP 各通路作用 | lp_input、lp_anchor、lp_score、shaping_coef 单独消融 | 同执行器通路之外的设置；根 LP 成本仍包括归一化/指标用途 |
| 表示中的组合关系 | pair_features=False，保留 pair_score=True | 评分字典和训练设置不变 |
| 字典中的组合项 | pair_score=False，保留 pair_features=True | 编码表示不变 |
| 跨 N/M/分布 | `--synthetic`；Chu 全量、按 N/M/容量比报告 | 冻结模型；测试种子与训练/验证不同；同测试生成参数与 SHA |

测试系数范围/相关噪声/偏移在 EvalConfig 独立配置，不随训练配置改变。
Chu best-known 只是参考值，合成测试只报 LP-gap；不能把二者平均成同一种 gap。
主结果必须报告尾部和紧容量子组；更大 N 的低 gap 不自动等于更强规划能力。
greedy 与 best-of-K 分开；本实现没有局部搜索或修复阶段。

`runs` 保存完整展开配置、种子、训练实例种子与 SHA、验证实例清单、实际优化预算、
解序列、Git commit/dirty diff、实际源码副本和硬件依赖信息。
`checkpoints` 保存初始 actor、当前 actor/critic、优化器和随机状态；模型 SHA 在旁置 JSON。
评估保存冻结 checkpoint SHA、数据 SHA、逐实例 SHA、所有采样解序列与胜者 θ 轨迹。
读取/输出文件和独立可行性审计不计入推理计时；每臂每阶段计一次根 LP 加全部策略执行时间。

`latest.json` 指向该版本最近一次保存运行的 synthetic-best，而不是跨 seed 的最好模型。
正式多 seed 比较应显式指定每个 checkpoint，避免把最近运行误当成汇总最优。
反复查看 Chu 或同一合成测试集属于研究反馈；最终论文测试需预先保留新的独立实例/种子。

## 6. 尚未实现和证据边界

没有实现合法 θ 见证搜索、冻结多候选续行监督、每步精确残余 LP、多 seed 置信区间汇总，
也没有将这类功能隐式加入主策略。交接文档 Q-3 等诊断仍是后续研究工作。
目前的回归测试与小规模端到端检查只确认程序契约；没有完成正式训练、全量 Chu 性能实验、
收敛判定或受控泛化增益验证。默认值应作为可复现的起始设定。
